## Модули:
- UserAPI:
	> GetAvatarByID - по заданному идентификатору получить BitmapView с аватаркой
	> GetCurrentName - получить StaticTextView с именем пользователя
	> GetCurrentAvatarID - получить номер аватарки пользователя
- SpaceAPI: модуль для взаимодействия с пользовательским файловым пространством
	> GetCurrentSpace (! нестабильный интерфейс, лучше возвращать точечный неизменяемый объект )
- WebAPI: модуль для сетевого взаимодействия
	> GetDevicesNear (возвращается StaticListView на статический массив с DeviceInfo ! тоже может быть нестабильным - неатомарным)
- TimeAPI: модуль для получения времени (в том числе и даты) - может активно использоваться анимациями и прочими элементами завязанными на времени
	> GetCurrentMs - получить текущее значение с момента запуска
	> GetCurrentTime - получить текущее время (часы, минуты, секунды)
	> GetCurrentDate - получить текущую дату (год, месяц, день)
